# one_num_type

The Elpi files of [one_num_type](https://github.com/ybertot/one_num_type)
by Yves Bertot (`srcElpi/*.elpi` at commit
`d34d77dcd5ca6851378a15a57b0ae4270f2c85bd`), copied unchanged under the MIT
license (see [`LICENSE`](LICENSE)). They are Coq-Elpi programs, used here as
a test set for error recovery: `recov.py fuzz` damages them and checks what
is recovered.
